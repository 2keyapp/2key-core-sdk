# Tenant catalogs moved

Canonical CatalogSeed packages live in **[`2key-billing-sdks`](https://github.com/2keyapp/2key-billing-sdks)** under `packages/javascript/catalogs/`.

```ts
import { CATALOG_SEED, SERVICE_ID } from "@2key/catalog-idr";
```

See that repo’s `docs/TENANTS.md`. Shop JSON (`2key-idr-seed-templates/catalog.json`) is commercial SKUs, not AuthZ.
