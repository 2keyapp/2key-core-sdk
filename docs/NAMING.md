# Naming: 2key-core-sdk

This repository is **`2key-core-sdk`** in all remotes, docs, and CI — **Rust native only**.

| Historical term | Current meaning |
|-----------------|-----------------|
| `dp-sdk` | Deprecated **repo** name. Use `2key-core-sdk` (Rust) + `2key-browser-sdk` (TS). |
| `@2key/dp-*` | Delegate Permissions **npm packages** in **`2key-browser-sdk`**. |
| `@2key/browser-sdk` | Unified browser AuthN + AuthZ + Billing SDK (`2key-browser-sdk`). |
| `two-key-core` | Private billing native core crate (Binary Private Core). |
| `two-key` / `two-key-cli` | Desktop CLI binary released from this repo. |

Do not create a separate public or private repo named `dp-sdk`.
