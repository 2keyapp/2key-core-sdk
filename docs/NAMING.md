# Naming: 2key-core-sdk

This repository is **`2key-core-sdk`** in all remotes, docs, and CI.

| Historical term | Current meaning |
|-----------------|-----------------|
| `dp-sdk` | Deprecated **repo** name. Use `2key-core-sdk`. |
| `@2key/dp-*` | Delegate Permissions **npm packages** inside this repo (kept for import stability). |
| `two-key-core` | Private billing native core crate (Binary Private Core). |
| `two-key` / `two-key-cli` | Desktop CLI binary released from this repo. |

Do not create a separate public or private repo named `dp-sdk`.
